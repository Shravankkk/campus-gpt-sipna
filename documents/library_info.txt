Library Area: The central library is spread across two floors and provides space for reading, reference work, and academic study.
Book Collection: The library has textbooks, reference books, journals, magazines, project material, and other academic resources.
Digital Resources: Students can use digital learning resources and library services for academic preparation.
Book Bank: The library may provide book bank facilities to support students with important subject books.
Library Software: Library services are automated using library management software, which helps with book search and circulation.
Barcoded Books: Books are barcoded so that issuing and returning books becomes faster and easier.
Reading Room: Students can use the reading room for quiet study, exam preparation, and project work.
Library Card: Students should carry their college ID card or library card while using library services.
Silence Rule: Students should maintain silence and discipline inside the library.
Return Rule: Borrowed books should be returned on or before the due date to avoid late fine or inconvenience.
Reference Section: Some books and journals may be used only inside the library and may not be issued for home reading.
